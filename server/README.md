# XABAR SOS Backend Server (Render Deployment Guide)

O'zbekcha:
Ushbu Node.js server Render.com xizmatida bepul joylashtirilishi (deploy) mumkin.

### Render Sozlamalari (Render Settings):
1. **Repository**: `https://github.com/3242242erwrwr/XABAR-SOS.git`
2. **Environment / Language**: Node
3. **Root Directory**: `server` (yoki loyiha ildizida `package.json` va `index.js` joylashtiring)
4. **Build Command**: `npm install`
5. **Start Command**: `node index.js`

Server ishga tushgach, Render bergan domen manzilini (Masalan: `https://xabar-sos.onrender.com`) ilovadagi **Sozlamalar** tugmasi orqali kiriting!
